# infrarust_config

Configuration layer of the [Infrarust](https://github.com/Shadowner/Infrarust)
Minecraft reverse proxy.

Defines the TOML configuration schema (proxy settings, server entries, domain
index, validation) plus the migration path from the legacy v1 YAML format.
Consumed by `infrarust-core` and the `infrarust` binary.

- Repository: <https://github.com/Shadowner/Infrarust>
- Configuration reference: <https://infrarust.dev>
